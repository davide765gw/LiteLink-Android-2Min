PROJETO ANDROID + SITE

Não há um APK pré-compilado neste ZIP. O projeto pode ser aberto no Android Studio e compilado via Build > Build APK(s).

ALTERNATIVA GITHUB
1. Crie um repositório GitHub e envie OS ARQUIVOS E PASTAS DESCOMPACTADOS desta pasta para a raiz, preservando .github/workflows/build-apk.yml.
2. Na aba Actions, execute "Gerar APK" (ou faça push em main).
3. Baixe o artefato LiteLink-APK na execução e extraia app-debug.apk.
4. Renomeie app-debug.apk para LiteLink.apk e coloque ao lado de site/index.html.
5. Publique o conteúdo da pasta site em GitHub Pages ou Cloudflare Pages. Clique no botão para baixar e instalar o APK.

COMPORTAMENTO
- Ativação manual na primeira utilização com botão claro e opção Parar rotina.
- Teste manual para abrir link TikTok Lite, ou loja se ausente.
- Tentativa periódica em ~30 minutos (Android pode atrasar ou bloquear o lançamento de tela em segundo plano).
- Sem notificações do aplicativo.
- A instalação Android exige confirmação do usuário. O site não instala sozinho.
- O link do evento é preenchido no app. Caso vazio, abre a tela inicial do TikTok Lite.

Este projeto não garante abertura em segundo plano em Android recente ou sob otimização de bateria.
